# MyFontTester

MyFontTester is a versatile and user-friendly tool designed to help designers, developers, and anyone interested in typography to preview and compare different fonts with ease. Whether you are refining your website’s style or experimenting with new typefaces for a print project, MyFontTester streamlines the process of exploring and evaluating font choices.

## Features

- **Font Preview:** Instantly view how various fonts look with custom sample text.
- **Font Comparison:** Compare multiple fonts side-by-side for efficient decision-making.
- **Customizable Text:** Enter any text to see real-time font rendering.
- **Responsive Design:** Works seamlessly across devices and screen sizes.
- **Easy Integration:** Simple setup for quick use and testing.

## Getting Started

To get started with MyFontTester, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/poiut23/MyFontTester.git
   ```
2. **Open the project folder** and follow the setup instructions provided in the documentation.

## Usage

Simply launch the application and begin typing or pasting your sample text. Select fonts from the available list to preview and compare them instantly. Adjust settings as needed to tailor the display to your preferences.
